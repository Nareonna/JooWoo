# JooWoo ✧ для Tavo

Сайт с темами, пресетами, плашками и плагинами JooWoo для Tavo.

- `index.html`, `style.css`, `app.js` — сам сайт (без сборки, просто статические файлы)
- `img/` — картинки сайта
- `files/` — файлы для скачивания (темы `.thm`, пресет, лорбук, наборы регексов)

Публикуется через GitHub Pages: Settings → Pages → Branch `main` / `(root)`.
