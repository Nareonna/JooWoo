# JooWoo ✧ для Tavo

Сайт с темами, пресетами, плашками и плагинами JooWoo для Tavo.

- `index.html`, `style.css`, `app.js` — сам сайт (без сборки, просто статические файлы)
- `img/` — картинки сайта
- `files/` — файлы для скачивания (темы `.thm`, пресет, лорбук, наборы регексов)

Публикуется через GitHub Pages: Settings → Pages → Branch `main` / `(root)`.

## Жанры и корзина

- Жанры (Реализм и «Скоро») — в `tools/versions.json` → `modes`. Переименовать, добавить или убрать «скоро» (`"soon": true`) можно прямо там. Разделы сайта с `data-mode="realism"` видны только в реализме; плагины — во всех жанрах. Ссылка на жанр: `?genre=soon`.
- У файла в `items` поле `"mode": "realism"` — он показывается только в этом жанре. Без `mode` — во всех.
- **Корзина**: положи новый файл в `files/`, поменяй в `versions.json` `ver`, `date`, `ru`, `en` и запусти `python3 tools/build.py` — старый файл сам переедет в `files/archive/` и появится в корзине.
